# Roadmap

## Now

- Discover marketing and GTM repositories from GitHub.
- Rank candidate repositories.
- Extract structured capabilities.
- Generate skills, workflows, prompt packs, and a manifest.
- Review generated updates through pull requests.

## Next

- Improve scoring beyond stars and keyword relevance.
- Add richer examples for each generated capability.
- Add a browsable catalog of generated assets.
- Add validation coverage for all generated JSON and manifest paths.
- Add a no-credential demo path for first-time users.
- Track human review notes as feedback for future extraction quality.

## Later

- Add embedding search over generated capabilities.
- Export generated skills into agent-specific formats.
- Add a small web UI for browsing generated capability cards.
- Add quality scoring for generated prompts and workflows.
- Build an outcome-scored feedback loop for improving extraction prompts.
