# Examples

This folder contains curated examples that show what the pipeline produces.

## `alwrity/`

A public-facing example derived from the ALwrity digital marketing platform analysis. It includes:

- source repo summary
- extracted capability
- generated skill
- generated workflow
- generated prompt pack
- human-readable summary

## `demo-output/`

Generated locally by:

```bash
python scripts/demo.py
```

This folder is ignored by git because it is runtime output.
