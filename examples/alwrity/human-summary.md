# ALwrity example summary

This example shows the pipeline turning a public marketing automation repository into reusable agent assets.

## Extracted capability

ALwrity is interpreted as a digital marketing capability covering content planning, content generation, publishing, analytics, SEO, and social account management.

## Generated skill

`skill.json` describes the reusable capability in a structured way:

- triggers
- inputs
- outputs
- execution steps
- use cases
- reusable patterns
- prompt templates

## Generated workflow

`workflow.json` maps the skill to a compact execution flow:

1. analyze repository metadata
2. extract reusable patterns
3. map patterns to marketing use cases

## Generated prompt pack

`prompt-pack.json` packages reusable prompts derived from the capability.

## Why it is useful

A marketer, GTM engineer, or agent builder can inspect this output and quickly understand what parts of the source repository might be reusable in an AI-assisted marketing system.
